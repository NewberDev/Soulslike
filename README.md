# 🎮 [게임 제목 : Soulslike]
------------

> **프로젝트 목적:** GAS(Gameplay Ability System)를 활용한 어빌리티 기반 전투 흐름과 어트리뷰트 관리, 확장성 있는 액션 게임 구조 설계를 깊이 있게 학습하기 위해 제작한 1인 개발 프로젝트입니다.

## 📌 프로젝트 개요

* **개발 인원:** 1인 개발
* **개발 기간:** 2026.05 ~ 2026.07 (약 3개월)
* **사용 엔진:** Unreal Engine 5 
* **장르:** 3D 3인칭 소울라이크 액션

<br>

### 🎮 게임 설명
몬스터의 패턴을 분석해 공략하는 소울라이크 게임입니다. SP(Stamina) 시스템으로 전투 리듬을 설계하고, GAS를 도입해 체계적인 상태 관리와 공방의 재미를 구현했습니다.

<br>

---

## 🛠️ 핵심 구현 사항

### 1. GAS 기반 입력 및 액션 파이프라인
Lyra 프레임워크의 설계를 분석하여 입력이 GA(Gameplay Ability) 실행으로 이어지는 파이프라인을 구축하고, Data Asset을 활용해 유연성을 확보했습니다.

### 2. 애니메이션 동기화 (CAS & Motion Warping)
타겟의 위치와 방향에 따라 궤적을 실시간 보정하여, 잡기 및 뒤잡기 등 캐릭터 간의 자연스러운 상호작용 연출을 구현했습니다.

### 3. IK(Inverse Kinematics) 기반 상호작용
지형 경사에 맞춘 Foot IK와, 문을 열 때 캐릭터의 손이 손잡이 궤적을 자연스럽게 따라가도록 Control Rig를 적용했습니다.

### 4. 액션 타격감 및 전투 시스템
ANS(AnimNotifyState)를 활용한 정밀한 공격 판정과 Hit Stop, Camera Shake 연출을 연계하여 무게감 있는 타격감을 완성했습니다.

### 5. Physics Asset 기반 물리 연출
Physics Asset을 이용한 2차 애니메이션(Secondary Animation)과 피격 및 사망 시 실시간 물리 충돌을 반영하는 래그돌(Ragdoll) 시스템을 구현했습니다.
